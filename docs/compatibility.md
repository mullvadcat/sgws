## 后续建议

- 在用户确认 Safari 可继续使用后，补跑 Safari 的空筛选、`T03,T16`、1280×720 与 1920×1080 游戏画面。
- 在安装 Firefox 的环境重跑规则与视觉矩阵。
- 有实体手柄时记录型号、系统映射及按键保持/断开/重连的真实结果。
- 用户本地打开 `file://` 场景，确认错误提示与 HTTP 恢复说明；本 Agent 浏览器当前策略不允许直接验证。
- 若提供能够落盘的浏览器截图导出能力，再保存 125% 缩放下的菜单和 HUD 截图。
